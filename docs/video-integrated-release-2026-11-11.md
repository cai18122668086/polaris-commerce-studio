## 发布实现

`deploy/video_studio/integrated_release.py` 分为 prepare、rehearse、apply、verify 阶段。它记录当前视频 API、前端及代理镜像，生成服务器私有回滚配置，保留所有其他线上容器。

发布前对数据库和对象存储做配对备份，在隔离网络内恢复并演练 `20261107_0041` 到 `20261110_0051` 的迁移。切换前再次备份数据库、对象和视频文件。迁移只添加结构，启动失败会恢复旧服务配置，保留数据及新增表。

剪辑和规划使用独立队列，单并发 worker 和独立维护进程。模型、原库、字体、写作库及模板样片按摘要校验后只读挂载。保留生产 SuperTokens 身份、原媒体卷及现有服务凭据；不开启后台付费恢复或自动供应商切换。

前端以当前线上不可变镜像为基础，仅覆盖视频相关目录与类型文件，保留其他已发布电商界面。React、React DOM 和 RSC 使用 19.2.9 安全补丁，见 [官方公告](https://github.com/advisories/GHSA-xqc2-xf4c-x3h3)。

API 仍可不安装剪辑依赖独立导出接口。Python 3.12 剪辑镜像使用 `requirements.editing-api.lock`，与原 API 锁文件的 88 个包版本一致，并包含适用轮子的摘要；不改变其他服务的 Python 3.13 镜像。
