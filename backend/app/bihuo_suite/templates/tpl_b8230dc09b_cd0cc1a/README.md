# M7 variable full-script native application

Host API compile_request(resolved, *, source_path, fonts, creative_options, ffmpeg='ffmpeg', size=(1080,1920)), render_mp4(cfg, output_dir). There are no fixed source bytes, duration, scripts,101-token/14-cue counts or cue indices in runtime. Current526/101/14 is a regression fixture only. Host supplies actual transcript tokens and full semantic captions.

M7 has native image/video slot count0. All material inputs are disclosed as unused; no upload count creates a borrowed gallery or placeholder. Capabilities title=true, subtitle=false, name_card=true, images=false. Source room is retained in a full shot then the native rounded square-like window over its original static grid. The cut follows the next actual semantic cue after opening_end; it is a native hard cut, not an invented morph. No alpha/model is needed.

The portable copies of SC-CUE-SPLIT and SC-GLYPH-STAGGER use the same pure split/shadow/glyph math, only relative imports are rebased. Each cue grows as one native whole phrase; optional complementary upper/lower exit preserves per-line order. The current automatic split policy chooses real terminal semantic closures, not the reference's cue numbers. Original source's six designated split occurrences are not imposed on arbitrary new scripts. Event sampling is native25fps; actual FA milliseconds are retained separately and never rewritten. The headline uses the last planned emphasized words and actual token starts, with complete counted glyph/size/advance lists. Multi-character tokens share their real measured start; no fake uniformly subdivided glyph FA. The existing1frame entry lead can first sample10–30ms before its glyph's actual spoken start.

Empty/disabled identity omits the entire role; name-only/description-only are real independent conditions. Opening title has native typography and fade; no independent subtitle field is claimed. Long cues use natural font width<=1000/max3lines; headlines are naturally sized and guarded against overflow. The original room sampler preserves the approved M7 crop/occupancy, including its native square-window fit. The final fade uses the real clip tail after speech where possible.

Dependencies Python3.12+, Pillow/numpy/OpenCV and ffmpeg/ffprobe. Font and helper bytes are included and bound in bundle.json; caller fonts override. No old whole-scene renderer or skill path is imported. No new model/ASR/FA, no old reference re-encode and no pixels from a finished reference in clean output. Raw/font/curve source uncertainties remain recorded in the old frozen suite. This package does not claim formal03/04/08 or new visual approval.
