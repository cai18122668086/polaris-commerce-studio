# Check the whole written story before image generation

No generated images exist here. Compare ALL target_screens, approved copy and
commercial_adaptation against the source_sequence observations, story_mapping and
resolved_facts. This is a content check, not a fresh pixel inspection or image audit.

Return one unit_check per source screen in order. Compare five ordered dimensions:
role_fidelity, information_gain, semantic_handoff, evidence_fit, source_coverage.
Give concrete distinct evidence citing screen IDs, source jobs, actual proposed
copy or fact IDs. Do not infer correctness from structural field completeness.

Find a source mechanism reduced to another ingredient introduction, multiple
different source jobs collapsed into the same claim, missing answer-to-next-question
links, and composition percentages misused as outcome proof. A truthful fact alone
does not justify changing a screen's job. Judge the entire first-to-last progression.
Same keywords across promise, explanation and proof are allowed if the argument
advances. Source-intended repetition is allowed. Physical packaging words repeated
across product images are identity, not redundant campaign copy. Do not demand all
available product facts appear or impose a fixed selling-point sequence.

Set revise_mapping true only when an actual assignment or handoff must change.
Otherwise describe the local copy/plan correction. List every material mismatch.
PASS requires every comparison true, no mismatch and no mapping correction. A failed
comparison needs an actionable explanation, not a generic statement of repetition.
