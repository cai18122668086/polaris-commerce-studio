# 底图五维度与自动选择

改编自 baoyu-cover-image（MIT）的 Type / Palette / Rendering / Text / Mood 五维度与 auto-selection 规则，
收窄到「真人口播短视频封面」：渲染固定为摄影质感，文字密度固定为「只有标题」（文字由程序排版），
所以实际只需要自动选 **构图类型、配色、情绪** 三项。

代码读取下面三个表（`| 信号 | 取值 |` 格式，信号用「、」分隔，按表内顺序第一条命中即用，都不命中用「默认」行）。

## 构图类型 type

| 信号 | 取值 |
|---|---|
| 测评、开箱、新品、上新、对比、实测 | hero |
| 干货、教程、方法、步骤、技巧、攻略、清单 | typography |
| 故事、经历、日常、vlog、探店、旅行 | scene |
| 默认 | hero |

- hero：人物为视觉主体（占画面 50%–65%），背景简洁有景深。
- typography：人物退到一侧或下半，给标题留出大面积干净区域（≥40%）。
- scene：保留真实环境氛围，柔和自然光，背景有故事感但不杂乱。

## 配色 palette

| 信号 | 取值 |
|---|---|
| 美食、餐、咖啡、烘焙、家居、母婴、生活 | warm |
| 护肤、美妆、穿搭、珠宝、高端、品质 | elegant |
| 健身、户外、植物、自然、养生、茶 | earth |
| 促销、优惠、福利、大促、爆款、限时 | vivid |
| 默认 | warm |

- warm：奶油白、米色、暖橙点缀，柔和暖光。
- elegant：石膏灰白、暖灰、香槟金点缀，克制高级。
- earth：橄榄绿、陶土色、沙色，自然光。
- vivid：暖红、明黄、橙色，高对比但不刺眼。
- 所有配色都**不得以蓝色、紫色或蓝紫渐变为主色**。

## 情绪 mood

| 信号 | 取值 |
|---|---|
| 必看、千万别、震惊、绝了、避坑、踩雷、爆款、限时 | bold |
| 高端、品质、质感、专业 | subtle |
| 默认 | balanced |

- bold：对比和饱和度略提高，画面更有冲击力。
- balanced：正常对比与饱和度。
- subtle：低对比、低饱和，留白更多。
