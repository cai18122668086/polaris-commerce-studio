## 前后端实现

三栏工作台继续按用户提供的同行截图组织：口播原片、竖版模板画廊、任务历史，底部保留主入口。默认直接展示八款，可按名称搜索和分类筛选；素材要求、样片来源、成员与技术记录按需展开。新五款卡片使用本期真实成片封面，前四款显示“人工调整版”，方格纸显示“人工样片”。

上传原片可从已完成任务恢复并直接预览，不再刷新后只有转录却找不到原片。新增原片播放接口校验工作区、所有者、项目和源 SHA，支持 HTTP Range，并按保存的允许视频 MIME 返回。任务历史新增模板名与人工候选来源，便于找到正确版本和下载入口。

新六款准备请求加入版本化风格策略：只把该模板可用且未避用的成员与 Z-M00 空镜交给模型，加入实际逐词时钟；必须包含至少一个本款招牌组。招牌组所需素材全部缺失时，准备结果解释阻塞条件，并在调用模型前阻止收费。原有两款以及历史捕获请求的冻结快照不回写。

针对实际响应问题做了两处修正：一是“分别”不再被单字“别”误判为否定，真实“别”“不是”等仍受保护；二是仅对 JJ-S01、AH-S05、AH-S09 的无媒体解释/条件/顺序关系，投影重复的槽内关系标注。该适配不改变动效组、显示文字、词点、时间、媒体和渲染参数；保存原始响应、适配版本和改动 beat ID，来源校验会重做适配并核对回执。

实际模型仍把长句放进短字槽，后续新准备会额外发送原生 `content_capacity`，并明确 4 字槽、完整否定与条件要求。这一提示改进已通过静态与合同测试，本批额度已用完，没有再收费验证其新首轮成功率。

Windows 原生旋转图卡缺少 WebP MIME 映射会报 TypeError，渲染入口现显式登记 image/webp；不修改原引擎文件、字体、配乐或原生动作。
