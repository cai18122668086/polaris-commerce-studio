# 苹果极简动效模板候选版

与同事提供的 Motion 作者包采用相同组织思路：动效组件、参数、组合配方和本地导出入口。此处的 Motion 指可执行工程包，不是视频编码格式。网站通过 `suite_plan` 任务调用本包；未验证第三方 MotionGit 客户端导入。

组件分为 `visual.py`（人物、开场和主字幕）、`media.py`（资料窗接力）和 `information.py`（设置行、功能卡、引用结论）。`recipes.py` 接收一次全文规划解析出的词点、文字与素材，组织完整流程。渲染过程没有模型调用；素材录屏默认静音，原口播不变速。

候选版.2使用 `tengli.apple-suite-plan/2`：同一次全文规划必须给出覆盖全部实录词的字幕分句、自然换行及每句关键词。服务器核验全片覆盖、词语边界、每行容量与关键词归属；渲染器直接显示这些分句，最多两行，不再按字数或秒数重新截断。画面切换只改变字幕底色对比，不重切句子或丢掉标蓝。

安装本目录的 `requirements.txt`，另备 FFmpeg。网站负责核验字体、原片与素材并生成 `apple-minimal-render/1` 配置。也可从本地项目工作目录运行：

```powershell
python <包路径>/adapter.py check --input <本期配置.json>
python <包路径>/adapter.py export --input <本期配置.json> --output <新输出目录>
```

输入路径应为绝对路径或相对当前工作目录。字体与本期视频不包含在代码包内，应由使用者提供。实际画幅仅验证9:16、25fps；1080×1920和540×960已真实编码。标题过长会自然换行和适度缩字号，仍超容量则明确报错，不截断内容。

当前为候选版：标题字体为近似候选，参考配乐和音效未复刻。先行两组用户认可保存在工程 `reviews/pilot/user-approval-v4.json`，不自动扩大为其他内容或所有输入的认可。网站队列使用本地协议响应完成过真实编码、预览、高清确认与Range下载验证，不代表新付费模型的语义匹配质量已经验收。
