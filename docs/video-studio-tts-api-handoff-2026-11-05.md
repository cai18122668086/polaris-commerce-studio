## 价格与一分钟成本

本次验证的实际单价为：

- Turbo：120 元 / 百万输入字符，即 1.2 元 / 万字符。
- HD：210 元 / 百万输入字符，即 2.1 元 / 万字符。

两次实扣分别等于 45 × 120 / 1000000 和 45 × 210 / 1000000。**本次在该平台，一个汉字按一个输入字符计费。** 前期按 MiniMax 官方“一个汉字算两个计费字符”估算的 Tao 成本已被本次实际扣费修正；不再沿用 Tao Turbo 约 0.082 元、HD 约 0.143 元的旧估算。

此前一分钟样本的稿件为 368 字符。以本次单价换算，同稿仅配音预计：

- Turbo：368 × 120 / 1000000 = 0.04416 元，约 4.4 分钱。
- HD：368 × 210 / 1000000 = 0.07728 元，约 7.7 分钱。
- 现用 QuanYu 同稿曾实付 0.184 元，以上分别少约 76% 和 58%。

上述一分钟成本是同稿按字数计算，没有在 Tao 再生成完整一分钟。费用不是按音频分钟数计，语速和停顿会改变音频时长。本次只证明当前分组下两次短文本的结算，长稿、多次失败、套餐或后续调价需要另行核对。

## 音色与情绪支持情况

已实测的只有 `Chinese (Mandarin)_Warm_Bestie` 这一个官方音色。MiniMax 官方有多种男女声、不同年龄与风格，以及粤语和其他语言音色；Tao 上具体可用清单和逐个音色调用尚未验收，不承诺固定数量。

在已认证请求中对 `POST https://newapi.qwqtao.one/v1/voice_clone` 发送空 JSON，返回 HTTP 404：`Invalid URL (POST /v1/voice_clone)`。没有上传真人录音，也没有创建、购买或付费调用克隆音色。

准确结论是：该站标准克隆路径不可用，未验证声音克隆；不能仅据此断言站方没有其他定制入口。MiniMax 官方模型有克隆能力，也不能由此推断 Tao 已开放该能力。

如后续确需克隆，应向平台确认上传接口、克隆入口、收费、音色归属、持久保存和渠道切换规则。官方创建的 voice_id 不应默认可直接用于该第三方平台。克隆不是本次已完成能力，也不是当前网站接入的前置条件。
