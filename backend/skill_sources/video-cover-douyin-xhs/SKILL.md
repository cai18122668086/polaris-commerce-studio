# 短视频封面（抖音 / 小红书）

后端实现：`backend/app/video_cover_*.py`。本目录是规则与提示词的唯一出处，代码在运行时读取
`references/background-prompt.md` 与 `references/dimensions.md`，改规则只改这里。

## 1. 输入

| 字段 | 说明 |
|---|---|
| 视频 | 剪辑完成的成片（优先）或口播结果 |
| 封面大字 `cover_text` | 默认 = 发布标题；用户可单独改（可与发布标题不同） |
| 平台 `platform` | `douyin` / `xiaohongshu`，只影响底部安全区与字号上限，比例都是 3:4 |
| 关键词 `highlight`（可空） | 标题里要加强的连续片段，必须是 `cover_text` 的子串 |

## 2. 流程

1. **挑帧**：在视频 5%–95% 区间均匀取 12 帧，YuNet 人脸检测（`bihuo_suite/subject.py`），
   评分 = 人脸置信度 × 人脸大小适中（脸宽占画面 12%–40% 最佳）× 清晰度（拉普拉斯方差）。
   取最高分帧，记下脸框。没有脸时取最清晰的帧，按「无人物」版式处理。
2. **定版式**：从 `references/layouts.md` 里按脸的位置选 **2 个不同结构** 的版式（不是换色），
   每个版式定义标题区（归一化坐标）和人物要让出的区域。
3. **AI 底图**：以关键帧为参考图调用站内生图（images/edits），提示词由
   `references/background-prompt.md` 填充，五维度按 `references/dimensions.md` 从标题信号自动选。
   硬约束：**画面里不得出现任何文字、字母、数字、Logo、水印、平台图标**；标题区保持干净、低细节；
   真人身份锁定；主色调不得为蓝 / 紫。输出 1080×1440。
4. **再测脸**：在生成图上重新检测人脸（模型可能移动了人物）；脸框外扩（左右 15%、上 25%、下 10%）为
   「禁字区」。
5. **排版**：Pillow + 站内字体（思源黑体 CN Bold，OFL）。自动断行（最多 3 行，避头尾标点），
   字号从上限往下试到放得进标题区为止；按标题区平均亮度选白字 + 深色投影或深字；可选关键词换暖色
   （熔光橙 `#E8742A` / 暖黄 `#F2C14E`）。必要时加半透明深色衬底条保证 200px 缩略图可读。
6. **核对**（全部通过才算成功、才扣费）：
   - 逐字：排出的各行拼接后与 `cover_text` 去掉换行完全相等；每个字都在字体字形表里（无豆腐块）。
   - 遮脸：任何文字外框与禁字区的交集面积 = 0；放不下就缩字号，仍放不下换下一个版式。
   - 色调：底图中「高饱和蓝紫」像素（色相 200°–290°，饱和度 > 0.35，明度 > 0.2）占比 ≤ 18%。
   - 尺寸：1080×1440。
   任一不过：该候选判失败，不扣费，记录原因。
7. **兜底**：AI 底图失败时，可用关键帧本身裁 3:4 + 程序排版生成「视频帧封面」（不调用付费接口、不扣费），
   界面上标明是视频帧。

## 3. 文字规则

- 标题用原文，**不改写、不增删字、不换标点**（来源：baoyu-cover-image「Do NOT invent or modify titles」）。
- 字不得压在脸上（来源：autocrew「任何文字都不得穿过脸和眼镜」）。
- 200px 宽缩略图下主标题仍能读清：字号下限 = 画面宽度的 7%。
- 不出现别家品牌、网址、二维码、平台 Logo、播放量等假数据。

## 4. 身份锁定（改编自 autocrew identity-lock）

- 关键帧里的真人是唯一身份真值：脸型、五官比例、发型、眼镜、服装保持一致。
- 允许：均匀肤色、补光、轮廓光、背景重绘、轻微景别调整。
- 禁止：瘦脸、放大眼睛、改眼距 / 鼻唇比例、换表情、换人、加多余肢体。

## 5. 验收视图

每个候选保存三视图供人工抽查：整图、人脸 100% 裁切、200px 缩略图。

## 6. 计费

动作 `cover_generate`，默认 7 积分 / 张（`video_credit_prices.py`），按实际成功张数结算，失败不扣；
由 `POLARIS_VIDEO_CREDIT_PRICES` 配置决定是否生效。
