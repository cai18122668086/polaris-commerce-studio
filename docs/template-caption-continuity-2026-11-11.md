# 模板示例的主字幕与场景衔接修复

本轮由用户要求与“完善模板分组与在线剪辑”窗口同时推进。独立工作树为 `C:/tl/tengli-template-caption-fix`，分支为 `codex/template-caption-continuity-20261111`，基于 `f50e357`。主窗口后续的 `c737518` 处理照片、口播和页面入口；本分支只修改后端字幕、原生画面验证和离线回放工具，不修改它的前端文件、数据库或服务进程。

## 实际改动

七条卡片完整示例已重新导出，并安装到本地网站正在使用的 `C:/tl/tengli-template-styles-20261111/product-examples`。七条新视频使用 `caption-fixed-*.mp4` 文件名，旧视频保留。旧清单已备份为 `C:/tl/template-caption-review-20261111/example-manifest-before.json`；安装通过原子替换清单切换指向，并检查并发修改。“操作实景”的原生短参考片、六条原生版式参考及其标识保持原样，未补造真实录屏业务样片。

新的 `tengli.caption-presentation/1` 适用于八款用户模板的干净原片后续渲染。保留原始词级时间戳和完整原声，优先以十二字以内的词语边界分页；合并过短的逗号分句，短停顿期间保留上一句，长停顿仍允许清屏。`caption-anchors.json` 另存 `speech_end_seconds`，清楚区分说话结束与字幕结束，时间戳不是重新识别或伪造的词点。

普通主字幕水平居中，基线稳定在画面高度的 84%，实际字形必须保持在底部 12% 的边界以上。需要普通主字幕的整帧原生场景等比放入字幕读区上方，以实测字号和行数决定其空间；主字幕不会被推到 96%～98%。这会在部分整帧设计周围增加留边，属于本次明确的版式调整，应结合修复样片审阅。原生完整字幕接管 LYO01/LYO04 对应的同一句实录时，去掉普通字幕的重复部分，保留原生文字机制和本来无需额外字幕区的完整人物画面。

相邻章节卡或相邻 AZL 板式之间，至多 0.8 秒的短空档可继续上一原生场景，避免突然回到原始人物画面再切走。重新渲染所延长的原生片段，人物沿原视频时钟继续，未用冻结尾帧代替运动。原生文字和声音事件保留原词点。补充视频或无法确定类型的补充素材不会自动延长，避免超出素材范围。

原生库、字体、图片、音效和音乐文件未修改。新的画面几何与字幕墨迹单独核对；声音验证使用对应的原生局部事件坐标，继续校验实际 FX 起音和混音字节，没有取消原验证。旧的非用户模板、已有烧录字幕的原片沿用原路径。

## 验证与复现

本轮 123 项相关回归通过，修改模块的 Ruff 和 mypy 通过。使用真实人物亮相编排从 `compile_episode` 重新编译，字幕和画面几何与修复回放完全相同。七条真实母版均经过原生检查、完整解码、实际字幕墨迹、音频对照及本地网站公共下载接口的 SHA256 核验。七条的 voice、FX、BGM WAV 均与相应旧版逐字节相同。

证据根目录为 `C:/tl/template-caption-review-20261111`。七条结果分别在 `product`、`knowledge`、`presenter-final`、`rotation`、`magazine`、`chapter`、`paper` 的 `outputs/episode.mp4`。每条的 `replay-evidence.json` 记录旧版、摘要、字幕策略、重复字幕接管和短空档接续。`website-validation.json` 记录实际网站下载与旧音轨对照，`regression.xml` 记录回归。`compiler-person` 是实际编译入口检查。`presenter`、`presenter-v2` 是诊断中间目录，交付以 `presenter-final` 为准。

从独立工作树、使用已有主实现 Python 环境执行 `tools/replay_template_caption_fix.py --previous <已完成原任务实例> --output <全新目录>`，可离线重放修复版。脚本不会读取应用 `.env`，不调用供应商，不写网站数据库。只有经过原封存输入、原生收据和文件摘要核验的未改原生片段才会复用；改变长度的片段重新编码。`--validate-existing` 仅对本轮已导出的文件重新执行现有核验，不重新编码。

`tools/install_caption_fixed_examples.py --review <七条已核验结果目录> --examples <本地显式示例目录>` 负责本地示例安装。它要求旧示例摘要与回放来源一致，拒绝覆盖已存在的修正版文件，并保留原清单。生产发布不在本轮范围。

## 主窗口合入

本分支应整体合入，包含字幕呈现模块、编译器、原生声音和版面验证适配，不能只复制字幕位置常量。主窗口可执行 `git cherry-pick codex/template-caption-continuity-20261111`。之后在合适的测试空档重启其后端或 worker，让后续新任务加载修复代码；本轮未替主窗口停止或重启正在使用的服务。本地网站卡片示例已通过独立清单更新，刷新可读取修正版，与后端代码是否已合入分开记录。

本轮新增供应商调用为零，未推送或部署生产。已核对关键帧、实际字形、声画时钟和编码结果；完整主观听感与最终风格仍由用户审阅。短原景闪回已定位并修正，不把正常 30fps 元数据等同于任意网络、设备或原片的所有卡顿都已消失。
